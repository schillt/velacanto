## Preserved evidence

Build 106's source, app hashes, signing evidence, and Debug/Release logs are preserved. Its macOS run passed **55 tests**: 25 library, 9 player, 12 presentation, 7 library-action, and 2 genre tests. Owner feedback across the independent playback, seeking, and UI candidates supports selecting this baseline; it does not supply an unperformed exhaustive device matrix.

Build 107, `5213f93bbffd601501233ad6ad5717ffb5125308`, is rejected and excluded. Its three additional system-media tests must not be counted as build 106 coverage. Its passing 58-test result did not prevent a physical failure.

## Evidence handling

Keep original applications, raw device journals, signing profiles, and certificates in private archives. Publish source identifiers, aggregate results, sanitized sequences and dependency notices. Do not publish credentials, server origins, account/media identifiers or raw traces. Preserve failed experiments without restoring them to active release code.

## Disclosure audit

Candidate text/filename review covered sources, tests, resources, scripts, workflows,
current documents and imported historical notes. No credentials, private keys,
private server URLs, raw logs or provisioning/certificate files were found in the
release tree. One historical private server display label and unnecessary absolute
artifact paths were sanitized. The three source PNG assets contain no text/EXIF
metadata chunks. Both built apps were additionally checked for the known private
server origin and private-key markers. This scoped scan is not a forensic guarantee
about arbitrary binary content or old Git history.

GitHub receives source and sanitized documentation, not signed archives, provisioning
profiles, raw logs or device journals. Distribution packages go only to Apple for
the approved TestFlight upload. Original local evidence is retained privately.
