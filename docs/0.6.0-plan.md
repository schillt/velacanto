## Completion policy

Every carryover gets one explicit disposition: accepted with linked evidence,
fixed and accepted on a named candidate, bounded investigation/evaluation with a
recorded decision, or explicitly deferred by the owner. An unchecked historical
matrix is missing evidence, not automatic proof of a current bug. An implemented
feature does not need to be rebuilt simply because its issue is still open.

The objective is to finish the current 0.6 backlog and prior-milestone carryover.
Later-roadmap work is inventoried separately below so nothing disappears. Moving
those projects into 0.6 requires an explicit scope decision. A release must not
claim all carryover complete while silently retaining unfinished required work.

  Record inherited evidence separately; changed source invalidates affected results.

  candidate. Promotion, GitHub Release, signed export, Apple processing and tester
  availability remain separate gates requiring their applicable authorization.
- [ ] Automatic TestFlight delivery remains main-only. Preserve owner-started
  manual delivery/post-actions/tester scope; this plan changes no Apple workflow.
- [ ] Update acceptance, release notes, known limits and What to Test from the
  actual final state. Review exact public content for private origins, credentials,
  personal media and device/account identifiers before publication.

Each evidence entry records: issue/criterion; exact source and installed build;
platform and route; ordered actions and debugger/Mirroring state where relevant;
automated result; owner-confirmed audible/server outcome when required;
pass/fail/pending; limitation and next owner. Keep raw/private traces local.

Only playback and Now Playing receive special admission priority. Audio never
waits for optional content; browsing screens remain equal and publish
independently. Follow [playback protection](playback-protection.md), existing
account ownership and cancellation. No second player, speculative retries,
watchdogs, cache purges or global serialization to mask unresolved failures.
