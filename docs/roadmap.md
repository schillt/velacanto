## Current development: v0.6

The published runtime baseline is corrected v0.5 source `62982bb`; later alpha
instructions preserve permanent branches and the release-milestone disposition
gate. Local v0.6 development and installations are recorded separately in the
[development record](0.6-development-record.md). Installed219 has an unresolved
owner-reported Home rebound/expanded-bar clearance defect (#207); passing tests
and local installation do not close that physical acceptance failure.

The owner explicitly directs parallel issue agents, reviewed serial integration,
and shared-feature plus UX/UI parity between iOS and macOS (#210). The
[execution ledger](0.6-execution-ledger.md) records active workers, queued packages
and remaining evidence against the current live milestone.

Priority outcomes include:

- Playlist-management parity and native authoritative server occurrence reorder
  (#64/#183), preserving duplicates, permissions and playback ownership.
- CarPlay automatic Now Playing presentation, working keyboard Search and clear
  native exit/back navigation (#209), alongside reconnect/input acceptance.
- UI consistency, readable related/overview sheets and final-row clearance
  (#192/#206/#207); accessible native controls and honest operation outcomes.
- Download storage management in iPhone system Settings (#208), retaining useful
  in-app item actions and current preferences. Bulk Profile removal waits for an
  accepted replacement; the native offline-HLS dependency remains explicit.
- Queue/lyrics, desktop scrolling, independent loading/artwork reuse, playback/
  network/codec checks, server favorites/history and account/sign-out privacy.
- Supported metadata/standalone artists (#19/#157), and local-folder index/catalog
  composition only as retained by the current GitHub scope (#112/#115).
- Native Handoff/continuity (#197) and optional default-off iCloud pin sync (#198).
  Both remain v0.6 features and requirements before v1; neither is implemented or
  accepted merely by appearing here.
- Bounded supported casting and modern Siri evaluations (#17/#199), focused
  maintainability, policy readiness and reconciled release evidence.

Multiple saved accounts (#18) and Navidrome/Subsonic (#21) are in **Post-1.0
Backlog**, following the owner's remote-plan changes. Do not reintroduce other
music-service providers from obsolete local planning text. Existing single-account
identity and lifetime boundaries support current work; removed multi-account
implementation is not an assumed prerequisite for Handoff.

## Subsequent milestones

Follow the live GitHub assignments rather than copying old version buckets.
Broader accessibility, large-library performance, discovery, startup and
architecture/maintainability work retain their own milestones; affected-flow
corrections are part of each current feature. Native HLS offline shipping (#189)
remains post-1.0 unless its Settings-storage dependency is explicitly reconciled.

Before any release/distribution, inspect every current milestone issue and active
Project disposition. Each must be completed with evidence, explicitly replanned
to a specific later milestone, or explicitly discarded with a reason. Unresolved
scope decisions block release. Local implementations, earlier authorization and
TestFlight activity do not bypass this gate. Keep source publication, accepted
behavior, signing/upload/processing and tester availability separate.
