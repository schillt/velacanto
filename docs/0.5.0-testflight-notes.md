# TestFlight notes — VelaCanto 0.5.0 Alpha Preview

Prepared for candidate **0.5.0 (216)**. Use these notes only with its verified
upload; Apple processing/tester availability is recorded separately in the
[acceptance record](0.5.0-acceptance.md).

## What's New

Native CarPlay browsing and playback; HLS streaming; separate iOS Wi-Fi/cellular
quality with Auto; Original/AAC offline downloads; easier playlist creation and
multiple-song management; improved search, artist pages, albums, queues, lyrics
and Mac layout. Mac credentials now use the Data Protection Keychain; an upgrade
may require signing in again. Basic Siri/system media controls remain available.

## What to Test

- Start music, skip forward/back, seek and advance through the queue. Expand Now
  Playing and browse artists/albums while listening; try background and AirPlay.
- In iOS Settings → VelaCanto, try Wi-Fi/wired and cellular streaming quality
  separately. Start a new track after changing a preset. Auto can preserve Original
  on suitable unmetered Wi-Fi/wired; constrained/cellular paths use lower ceilings.
- Download a new song using Original or an AAC preset, then play it offline.
  Try downloading while another song streams, cancel/retry, and removing a download.
  Changing quality does not replace an existing ready download.
- Create a playlist with Add Songs Next, search/select songs, then select/remove
  entries using Manage Songs. Removal should affect playlist membership only.
- On Mac, sign in if requested and verify relaunch retains the session. If a saved
  account-data mismatch appears, retry the previous server address/account before
  choosing local-data removal. Server music is not deleted by that local action.
- In CarPlay, browse Home/New/Library, start playback and select an Up Next entry.
  Queue editing belongs on phone/Mac. Please test on real head units when safe.
- Check multi-disc albums, search, artwork, lyrics following, queue opening position
  and Mac inspector/menu alignment in your usual appearance and text-size settings.

Please report the build, platform/OS, action order, quality preset, output route
and whether audio was audible. Include a short description of expected versus
actual behavior. Do not send passwords, tokens, full authenticated URLs or raw
server/device logs. Broader vehicle, server, route, accessibility and preset
coverage is still needed; these are test requests, not claims of completed checks.

## Known Scope

Jellyfin is required. Server download/transcoding permissions and capacity apply.
Auto uses connection policy, not a continuous adaptive bitrate ladder. Converted
downloads are AAC/M4A; native HLS offline downloads are not included. Pins are local.
Advanced Siri/Apple Intelligence catalog playback is not included. A conditional
media-URL token concern remains under investigation; use trusted HTTPS services
and consider server/proxy log handling.
