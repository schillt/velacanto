The SDK selects Get and NIOTransportServices, which bring the remaining packages below. The final release lockfile must retain these revisions unless a dependency change is separately verified.

The application bundles full notices, license text, exact source links and source-archive links, available from **Profile → Open-source licenses**. The Jellyfin SDK source is unmodified in the baseline; its source-availability notice is included. Preserve those notices with the release package.

These are resolved package-level dependencies, not a claim that every component in each package is linked into the final binary. Apple platform frameworks are supplied by the operating system. The SDK's GenerateAPI command plugin and openapi-generator binary are development tooling, not runtime products selected by the application.

The app uses SDK request models with its existing native URLSession adapter and AVPlayer delivery. The presence of NIO in the SDK dependency graph does not imply that this release introduces a new application-owned network manager.
