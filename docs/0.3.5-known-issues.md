# 0.3.5 accepted known issues

The owner explicitly elected to ship 0.3.5 with these defects and continue
reliability work afterward. Acceptance of a defect is not a fix or a passing test.
P0–P3 describe current delivery priority. The volume defect was a P1 acceptance
failure during development and is now explicitly deferred as P2 for 0.4. No new numerical release grade has been established.

## P2 — Volume can return to an older level

After changing volume in Control Center, the in-app native slider initially
matches. A subsequent slider adjustment or hardware volume-button press can
return to the last in-app level, with a real audible loudness change. The owner
reported this across outputs with Mirroring disconnected and after reopening
Now Playing. Initial slider/hardware checks passed but did not cover this sequence.

The pre-volume baseline adjusted normally. Standalone native-volume and
native-volume-plus-MediaSession experiments also adjusted normally. These
comparisons implicate integration but do not establish the cause. No app-owned
iOS volume binding or restoration write was found in the reviewed implementation.
Do not describe this as a proven OS, route, server or caching bug. There is no
verified workaround for the shipping build; Control Center/hardware controls
alone have not been proven immune while the affected app is active.

Disposition: **explicit owner-approved 0.3.5 release exception; keep the slider**.
Track and reproduce independently after release in [issue #173](https://github.com/schillt/velacanto/issues/173), milestone 0.4. Keep all control through public
APIs; do not add private slider access, automatic volume restoration or speculative
audio-session resets.

## P2 — Recoverable playback load failure

Occasional playback failures have been observed around track transitions. Pressing
Play recovered the affected song in the reported cases. The recent failure did
not demonstrate the historical loss of all app networking. Slow server response
is a hypothesis, not a proven cause. Preserve bounded evidence when it recurs;
do not claim permanent network reliability from successful short checks.

Disposition: owner accepted continued investigation after this release.

## P2 — Delayed or missing system artwork

Control Center/lock-screen artwork can lag or fail to appear intermittently even
when playback works. The owner reproduced the cosmetic symptom. A common caching,
network or metadata root cause has not been established.

Disposition: owner accepted metadata/artwork refinement after this release.
