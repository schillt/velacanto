## Publication and privacy

Review the exact candidate diff and intended assets under
[publication safety](publication-safety.md). Publish source, sanitized notes and
bounded evidence only: no private server origins, media libraries, device/account
identifiers, credentials, signing material or raw traces. A bounded review finding
no secrets does not prove all historical artifacts or endpoint logging safe.
The repository remains public-source proprietary under its existing license.

Maintain README/release notes for the branch being published. Record actual final
SHA, required/advisory hosted outcomes, export/upload identifiers and availability
without assuming an unsigned CI archive is a signed TestFlight build.
