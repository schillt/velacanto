# VelaCanto 0.5.0 — Alpha Preview

Release candidate: **0.5.0 (216)**. This candidate packages the accepted build 215
runtime with release metadata updates. Publication, hosted checks and Apple
availability remain separate; see the [acceptance record](0.5.0-acceptance.md).

## What's new

- Native CarPlay browsing across Home, New and Library, artwork, playback and
  view-only Up Next with track selection. Queue editing remains on phone/Mac.
- HLS remote playback with compatible-source preservation and bounded server
  conversion. Existing basic Siri and system media controls remain supported.
- iOS system Settings now offers separate Wi-Fi/wired and cellular streaming
  quality, including Auto, plus independent Original/AAC download quality.
- Verified offline AAC/M4A downloads alongside existing Original-file downloads;
  ready files are reused when settings change.
- Improved playlist creation, immediate Add Songs, searchable multiple selection
  and easier membership removal across iOS and Mac.
- Metadata-aware search and discovery, more responsive artist loading, original
  artist logos, clearer glass controls and softer content arrivals.
- Refined albums and library layouts, consistent square album cards, title
  truncation, multi-disc headings and optional duplicate filtering by disc,
  track number and title.
- Queue opens at Now Playing with history above; synchronized lyrics follow near
  the top, with clearer active-line styling and a bottom follow control.
- More compact/readable Mac transport, improved inspectors, native settings and
  a full-width profile footer.
- Modern Mac Data Protection Keychain with guarded account-data recovery. A fresh
  sign-in may be needed; no legacy credential lookup or migration occurs.

## Preview limits

Initial CarPlay operation and audible playback have owner acceptance; broader
real-vehicle/head-unit testing continues through the preview. Server permissions,
codec support and transcoding capacity affect playback/downloads. Auto is a
connection-policy heuristic, not continuous measured-bandwidth adaptation. Mac
streaming remains Original. Converted downloads are AAC/M4A files, not native HLS
offline assets.

Basic Siri playback controls are included; advanced Siri catalog requests and
Apple Intelligence features are deferred. Local pins do not sync between devices.
Server playlist reordering, collaborative/offline editing and additional providers
are outside this release. Further UI/accessibility refinement and broader route,
server and preset coverage move to the next milestone.

A conditional media-URL token privacy concern remains open. HTTPS protects transit
but does not establish safe endpoint logging. This preview does not claim that
finding is fixed. See [privacy guidance](playback-url-privacy.md).

See [What to Test](0.5.0-testflight-notes.md) for focused feedback requests. Upload,
processing, tester availability and public App Store release are not implied by
these notes.
