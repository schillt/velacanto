## Code finding and change

The previous `FoundationDetailTitle` stored the hero's global title-bottom
position as modifier `@State`. Hero geometry preferences therefore changed that
state continuously during scrolling, including long stretches where the toolbar
title's reveal value remained clamped at zero or one. This is a code-based
invalidation finding, not a measured frame-drop diagnosis.

The Mac modifier now owns a small `@Observable` measurement object in `@State`.
Raw title/toolbar geometry and the scroll threshold are observation-ignored; only
the derived reveal progress is observable. A dedicated toolbar leaf reads that
progress. Geometry changes can update the raw measurements without invalidating
the collection modifier, and saturated progress does not notify the title leaf.
Keeping the latest raw position still allows window/toolbar geometry changes to
recompute the correct reveal. The title is passed as current view input, with no
captured title or mutable-input state initialization.

The separate `FoundationMacDetailTitle.swift` owns the desktop measurement and
title presentation. The shared modifier delegates to it on Mac; the existing
iOS geometry, title and scroll-edge behavior remain intact. The preference key
is module-internal so both the existing hero and the new Mac modifier can use
one measurement contract. No general observation migration is introduced.

Presentation remains the same48-point smoothstep, text/subtitle typography and
padding, hidden sizing title, Reduce Motion behavior, noninteractive toolbar,
accessibility reveal and native toolbar-background suppression. Navigation,
Handoff, player, loaders, artwork and playback-priority admission are unchanged.
No new tasks, timers, logging, network work or caches are added.

Apple documents the property-read dependency boundary for an observable object
shared from `State` to a child in [State](https://developer.apple.com/documentation/swiftui/state)
and [Managing model data](https://developer.apple.com/documentation/swiftui/managing-model-data-in-your-app).
The deployment targets are already iOS/macOS27, above Observation availability.
