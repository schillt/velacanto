# Historical architecture visualization

`velacanto-app-structure.html` is the standalone interactive architecture and
delivery-slice explorer created for 0.1. Its delivery content and component
status are historical.

GitHub does not execute committed HTML in the repository viewer. Download the
file or open it from a local checkout to inspect the historical artifact.

Current editable diagrams and responsibilities live in
[architecture.md](../../architecture.md); current delivery status lives in the
[0.3 plan](../../0.3-plan.md) and [roadmap](../../roadmap.md).

Do not update this archived visualization when current architecture changes.
