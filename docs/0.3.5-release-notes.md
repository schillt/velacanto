# Velacanto 0.3.5 prerelease

An alpha prerelease with playback fixes and restored native controls, plus a
refined Now Playing screen. Distribution uses internal TestFlight; main promotion
and public App Store submission are outside this release authorization.
Requires iOS/iPadOS 27 or macOS 27.

- Improves queue continuity, including automatic advancement during background
  playback, and uses asynchronous audio-session activation.
- Restores Now Playing integration for Control Center and the lock screen, remote
  transport commands, seeking and shared artwork.
- Adds native AirPlay selection with audio-only playback routing. The tested
  Apple TV/HomePod setup could play without waking the television; receiver
  behavior is not guaranteed across every configuration.
- Adds synchronized lyrics, tap-to-seek lines and automatic return to the current
  lyric after idle browsing, where the library supplies timed lyrics.
- Brings lyrics and the queue into the artwork area with fades, improved contrast
  and native system typography.
- Adds native iPhone/iPad volume controls and Mac player-volume adjustment.

## Known limitations

The in-app volume control can jump audibly to a previous level after volume was
changed in Control Center. The owner explicitly accepted shipping this unresolved
bug. Playback can occasionally require pressing Play again after a recoverable
load failure, and system artwork can appear late or remain absent. See
[known issues](0.3.5-known-issues.md) for evidence and limitations.

This release does not add offline libraries, playlist editing, persistent
shuffle/repeat, CarPlay or playback reporting. See the
[acceptance record](0.3.5-acceptance.md) for candidate and distribution status;
release notes alone do not certify that an artifact has passed or shipped.
