## Security remediation

The development diff review found two P2 resource-exhaustion risks against a
malicious or compromised selected server. Both were fixed and independently
reviewed within their reported boundaries:

- `a9956ce`: native download reception enforces an immutable byte budget based on
  expected size and sampled temporary/destination capacity, retaining a 256 MiB
  reserve. Excess announced/received bytes cancel the transfer; rejected files
  cannot become ready downloads. See [download policy](offline-downloads.md).
- `6326b53` plus equivalent final fixture `8c7038c`: Songs activation loads one
  page; scrolling supplies further demand, and A–Z uses retained rows. Lifetime
  limits cover requests, raw membership and counted metadata, including duplicates
  and retries. Completed demand is consumed and accessibility scrolling is covered.

Preparation `0c8c547` and integrated `8c7038c` have identical source trees. Focused
trigger, legitimate-input and bypass/regression checks passed. Later Mac/account
presentation changes through `488d0af` are outside that security review. The review
is neither a full-history secret scan nor proof of every runtime security property.
