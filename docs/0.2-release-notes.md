# Velacanto 0.2.0 release notes

## Summary

0.2.0 is a focused quality release. It reworks SwiftUI presentation ownership
without changing the provider or playback boundaries, resolves the scoped UI
defects, and makes persistence failures easier to diagnose safely.

## Included

- Split root, catalog, artwork, mini-player, and Now Playing presentation into
  focused units with clearer ownership.
- Simplified catalog and artwork behavior where it is genuinely shared while
  retaining native iOS and macOS layouts.
- Fixed macOS sidebar behavior, album-art sizing, and content overlap with the
  Now Playing bar.
- Added native Play and Shuffle entry points for albums, artists, and playlists,
  plus a macOS playlist sidebar section.
- Hardened session/cache/reporting failure handling with privacy-safe logging
  and focused persistence tests.
- Retained the Xcode 26-compatible audio-session fallback while using the
  newer asynchronous API where it is available.

## Validation

- The strict pull-request quality gate passed locally and in hosted CI.
- iOS device and macOS acceptance were completed on the beta candidate; the
  promoted preview tree is identical to that accepted source.
- The final preview candidate passed the strict local gate before promotion.

## Known limitations

The current operational limitations are maintained in [Known issues](known-issues.md).
They include codec/server compatibility breadth, token-bearing playback URLs,
the iOS Simulator audio-session diagnostic limitation, and the absence of
offline playback and gapless guarantees.

## Next release base

`main` at tag `0.2.0` is the base for the next planning cycle. New work should
be scoped from the open roadmap rather than reopening the completed 0.2 issues.
