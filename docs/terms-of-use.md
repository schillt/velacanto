## Account security and actions

Keep your device and server credentials secure. Use a server you trust and an
HTTPS connection. Your server operator controls accounts, media availability,
permissions and server-side retention. NovoLuxor support cannot recover your
server password or administer an independently operated server.

Actions such as playlist edits, favorite changes and downloads can affect your
server or device. Check the action and account before confirming it. Removing a
playlist entry does not delete the underlying server song. Sign-out and local
storage cleanup do not delete your server account or guarantee deletion of
server logs or older backups. See the [privacy policy](privacy-policy.md).
