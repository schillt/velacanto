# Velacanto 0.3 stability acceptance

This matrix controls the internal preview and final 0.3.0 release. Automated
checks prove isolated behavior and compilation; platform, physical-device, and
real-server checks prove the complete experience.

## Release rules

- **Preview:** `alpha → beta → preview` may occur only after the stable OS 27
  SDK is available and all automated rows and preview smoke rows pass. The
  original August 19, 2026 checkpoint is not a release override.
- **Final:** `preview → main`, tag `0.3.0`, and final release notes require every
  row to pass or record an explicit accepted limitation.
- Record the exact commit, Xcode version, OS versions, devices, Jellyfin version,
  network class, source codec, and direct/transcode result.

## Platform and experience matrix

| Area | Required verification | Release criterion |
| --- | --- | --- |
| iPhone navigation | Home, Library, Search, details, mini-player, Now Playing, and Up Next in portrait/landscape. | Native hierarchy remains usable at supported sizes and playback persists. |
| iPad adaptation | Compact/regular widths, sidebar behavior, split view/multitasking, Now Playing, and Up Next. | No phone-only stretched layout or inaccessible action. |
| Mac adaptation | Sidebar/detail selection, global search, Profile footer, window resizing, keyboard/focus, and playback presentation. | Native navigation remains stable and content is not covered. |
| Home data | Continue Listening, Recently Played, Favorites, Recently Added, source entries, and all states. | No fictional content; loading, empty, error, retry, and signed-out states are honest. |
| Catalog actions | Favorite, Play Next, Play Last, Play/Shuffle, and navigation actions across all item surfaces. | Capability filtering and state remain consistent. |
| Mini-player persistence | Start playback, change primary destinations, use an active Search query/result action, push/pop details, and dismiss Now Playing. | One mini-player remains available when a playable current item exists; it neither disappears nor duplicates and does not cover controls or the keyboard. |
| Up Next | Reorder/remove upcoming items, shuffle, repeat, page expansion, and relaunch. | Explicit order is preserved; current/history remain safe. |
| Playback method | Exercise local, direct, and transcode paths. | UI matches the resolved method and never exposes provider internals. |
| Lyrics | Timed, untimed, unavailable, failure/retry, seeking, manual scroll, and follow behavior. | Text respects safe areas, never bleeds through the player, and remains accessible. |
| Album restoration | Cold, warm-cache, late-page, refresh, changed-query, and rapid detail navigation. | Return restores the same anchor; deliberate query refresh resets it. |
| Accessibility | Dynamic Type, VoiceOver, target sizes, contrast, Reduce Motion/Transparency, and meaningful labels. | Essential metadata and actions remain understandable and operable. |

## Device, server, and system-media matrix

| Area | Required verification | Release criterion |
| --- | --- | --- |
| Jellyfin journey | Connect, restore, Home, browse, search, favorite, play, edit queue, and logout. | The complete flow works without stale account data or secrets in logs. |
