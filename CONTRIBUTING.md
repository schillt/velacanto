# Contributing to Velacanto

Velacanto is proprietary source-available software. Its public source is
provided for transparency and project visibility; it is not offered as an
open-source project and no permission to copy, modify, distribute, or create
derivative works is granted by this repository.

## Issues

Use GitHub issues to report reproducible defects, security concerns, or
documentation inaccuracies. Do not include access tokens, passwords, server
addresses, personal media details, logs containing full request URLs, or other
confidential information. For a sensitive report, contact the project owner
privately instead.

## Pull requests

Do not open an unsolicited pull request or fork this repository for
development. Changes are accepted only when Chameleon Enterprise Ltd has
requested them and agreed the contribution terms in writing before work begins.

Invited contributors must keep changes focused, include appropriate tests or
validation evidence, and confirm that their contribution does not include
third-party code, media, or other material without the right to use it.

## Third-party material

Do not add dependencies, artwork, fonts, media, or other assets unless their
license and required notices have been reviewed and recorded with the change.
The project currently relies on Apple system frameworks and does not ship a
third-party package dependency.
