# Contributing to Velacanto

Read AGENTS.md and NativeFoundation/AGENTS.md. The rebuilt app is the sole active
target; old release tags preserve prior source. Use one isolated worktree per
assigned issue, preserve other work, and return focused commits to the integration
owner. Run root scripts/build.sh for actual Foundation checks. Keep changes
simple, provider-neutral and bounded; do not change frozen playback/networking
without explicit scope. Include exact verification and physical limitations.
Never commit credentials, signing profiles, private server/media data or raw
traces. alpha→beta→preview→main promotion is coordinated separately.
